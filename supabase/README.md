# Configuração do Supabase para o SisMA

1. Acesse o painel do seu projeto no Supabase.
2. No menu SQL Editor, execute o script `schema.sql`.
3. Em Settings > API, obtenha a URL e a chave pública da API.
4. Defina as variáveis de ambiente `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` no seu ambiente ou no GitHub Actions.
